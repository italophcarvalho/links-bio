# Links Bio

Repositório de páginas de link da bio. Cada cliente tem sua própria pasta na raiz e pode ser importado como um projeto independente na Vercel.

| Projeto | Pasta | Diretório publicado |
| --- | --- | --- |
| Cerimonial Infantil Legal D+ | `legal-dmais` | `legal-dmais/dist` |

## Publicar o Legal D+ na Vercel

1. Importe este repositório como um novo projeto.
2. Defina **Root Directory** como `legal-dmais`.
3. Use **Framework Preset: Other** e deixe o comando de build vazio.
4. O arquivo `legal-dmais/vercel.json` define `dist` como diretório de saída.

Os arquivos prontos para hospedagem já estão versionados. A publicação não depende de Python ou de instalação de pacotes.

Para adicionar outro prospect, crie uma nova pasta diretamente na raiz e importe essa pasta como outro projeto na Vercel.
